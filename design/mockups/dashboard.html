What the gutter does

144px gutter, right-aligned numeral. Display face 32/600, tabular figures so 07 and 47 occupy identical width and the left edge never ripples.
2Colour is value, not hue. #77898C at 22.5pt clears AA large-text (3.6:1); scale carries the personality, lightness keeps the 14px title on top of the hierarchy.
3Hover moves the numeral, not the row. Numeral → ink, shadow xs → sm, border → edge-strong. No transform, no lift, no scale. The accent is too close to the neutrals to carry hover, so value does it.
4Completion replaces the glyph. 28px ink square with a check occupies the same cell — deliberately not the accent, so "done" never reads as "clickable". A shape change readable before colour, plus strikethrough and the word Done.
5The number is the address. "Row 04" is sayable in a screenshare, and the edit drawer repeats it in its header so the row keeps its place.
6Same face, four scales. 132px empty-state figure · 44px hero count · 30px row index · 18px page numbers. One idea, applied four times.

The one loud thing in the product. Everything around it is one text weight, flat surfaces, and a single accent — that contrast is what makes the numerals read as intent rather than decoration. Build it as a grid column, not a pseudo-element: it has to hold a check square too.

The signature. Row grid 44px 22px 1fr auto 78px 118px 30px, gap 14, min-height 48 (compact — the shipped default). The index numeral is Big Shoulders Display 30/600 in #77898C — 3.6:1 at 22.5pt, above the AA large-text floor — and darkens to ink on row hover (row 03 is shown hovered): in a near-monochrome palette the hover cue has to be value, not hue. Completed rows swap the numeral for a filled ink check square, tint to #F4F7F7, drop their shadow, strike the title, and carry the word Done: three non-color channels before color does any work. Overdue is the only other place brass appears.

02Toolbar — search, filter, sort, new task
  • 1Search — 280px TextInput, magnifier in leftSection. Filters on keystroke; a filled query shows a clear button and the count in the hero drops to matches.
  • 2Status filter — SegmentedControl, All / Pending / Completed. Selected segment is teal-filled; the same control appears in the drawer, deliberately.
  • 3Sort — 168px Select: Due date · Recently added · A–Z · Status. Never deselectable; a list always has an order.
  • 4New task — the only filled button on the page, shown here with its keyboard focus ring. Opens the drawer in create mode.

Toolbar is one Paper, padding 14/16, controls in a 10px-gap row that wraps below 900px. Only one teal fill per surface: the primary action. Search and Sort stay neutral so the filled button reads as the single call to action.
